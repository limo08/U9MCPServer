2026-11-02 · v0.0.9 首次提交
U9Mcp 首个版本发布。底层采用 U9C OpenAPI：OAuth2 AuthLogin + 请求头 token、CommonEntity/Query 查询、/webapi/{Service}/{Action} 写操作；内置离线 U9C 元数据目录（628 paths / 157 Services / 838 schemas）。提供 107 个 MCP 工具，覆盖 17 个业务域，包括通用单据、采购、销售、库存、生产、委外、财务、成本、资产、审批、附件和只读 SQL 查询。附件使用 AttachmentFileUpload/Download，报表使用 Report/GetReportPdfFile 生成 PDF。SQL Server 直连保持只读，业务规则、审核流和编号规则统一由 U9C 服务端执行。
